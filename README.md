# PULSEWING

A procedural arcade flight game built entirely with HTML, CSS and JavaScript.

## Concept

PULSEWING is not intended to be a Flappy Bird clone.

The game uses:

- Procedural energy gates
- Increasing world speed
- Moving gates
- Collectible shards
- Combo scoring
- Temporary shields
- Deterministic random generation
- Mobile controls
- Keyboard controls
- Local high scores
- AI-ready game state API

## Controls

Desktop:

- SPACE = Pulse
- UP ARROW = Pulse
- P = Pause
- ESC = Pause

Mobile:

- Tap the game
